About these rankings

FPI is expected point margin against an average FBS team on a neutral field; the projected record is ESPN's simulation of each team's actual schedule. Preseason these are projections; once games are played the same numbers update with results. Move is places climbed and Δ the FPI's change since the point the buttons pick - every build is archived, so the choice runs from the last build (Sep 4) back to the season's first.

Rating is the ratings and the projected record, Odds what ESPN's simulations give each team, Resume what the schedule has been worth. Click any column header to sort by it; click again to reverse. Top 25 highlighted - the highlight follows the team, so the FPI top 25 stay marked however the table is sorted. On the Resume tab, SOS is strength-of-schedule rank (hardest first) and Rem SOS the same for the games still to play; SOR is strength of record - where an average top-25 team would sit with this resume - and GC game control, the share of game time spent in the lead.
