About these ratings

+14 beats -14 by four touchdowns on a neutral field. The whole division fits in 57 points. Scoring is the same idea for the total — how many points this team adds to a game, whichever sideline it is on. Ratings come out of the same model that prices Saturday, and carry the same caveats. Move is places climbed and Δ the rating's change since the point the buttons pick - every build is archived, so the choice runs from the last build (Sep 6) back to the season's first.
