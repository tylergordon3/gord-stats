How to read this page

Start / sit shows the lineup to set and colours what has to change to get there, by GS proj, this site's weekly projection (Yahoo's own sits beside it). Green comes off the bench into the slot named; red goes to the bench; blue stays a starter but changes slot for the kickoff order: Yahoo locks a player at his own kickoff, so the earliest games take the position slots and the latest take the flex — if Saturday night's receiver is scratched, the open slot is one any back, receiver or tight end can fill. Late-swap cover is, once the changes are made, the best bench player who could still take that slot: eligible for it and not kicking off any earlier. A player whose game has started is locked where he sits.

Opp vs pos is the opponent's row on the matchup strength page: fantasy points allowed to that position against what the offences it faced should have scored. 1.00 is par, green is soft, and the rank runs from 1 (the toughest, red) to 138 (gives up the most, green); FCS defences have no rating. Weather is the forecast for the game, in amber when it is bad enough to matter (rain, storms, snow, or gusts past 25 mph). Car% and Tgt% are the last 3 played weeks from the usage page. Waiver adds sets each free agent against the weakest starter he could replace, so the gain is what the lineup total would move by. Rebuilt several times a day (last: Sep 22, 5:33 PM EDT).
