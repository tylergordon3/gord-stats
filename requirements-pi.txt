# Runtime dependencies for the Pi's daily job — every section it publishes:
# the WNBA feed, the fantasy football rebuild, and the homepage render. That's
# what `gordstats.daily --tasks wnba,fantasy` touches.
#
# Deliberately not environment_pi.yml or fantasy's requirements.txt: the former
# carries the CBB model stack (scikit-learn, statsmodels) and scrapers
# (selenium, playwright, the KenPom wrapper); the latter is a full `pip freeze`
# of a dev environment including torch, which has no aarch64 wheel on PyPI at
# all. Neither is imported by the sections that actually run here.
#
# The college basketball model stack is included but the section is not enabled
# in TASKS yet: the feeds only carry current-season numbers once the season
# starts, so _cbb() refuses to run before tipoff (Nov 2). Installing the deps
# now means the switch is one edit to TASKS rather than a deploy on the night.

browser-cookie3
